# 📂 Projetos em destaque

### 📊 Dashboard de Acompanhamento da Migração de Sistema

Projeto desenvolvido em **Power BI** para acompanhamento de uma migração de sistema, utilizando indicadores, organização de informações e visualizações para monitorar resultados.

**Tecnologias:** Power BI • DAX • Excel

🔗 [Acessar projeto](https://github.com/Kofhe/-Dashboard-de-Acompanhamento-da-Migração-de-Sistema)

---

### 🏥 Dashboard Hospitalar — Power BI

Dashboard desenvolvido para análise de uma base hospitalar fictícia com **20.000 registros**, explorando indicadores de atendimento, eficiência operacional, qualidade e perfil dos atendimentos.

**Principais recursos:**

* 📊 Indicadores e KPIs
* 🔎 Filtros e segmentações
* 📈 DAX
* 🔄 Power Query
* 🧭 Navegação entre páginas

---

### 🗃️ SQL para Análise de Dados

Projeto criado para praticar SQL utilizando uma base hospitalar, evoluindo desde consultas básicas até análises mais estruturadas.

**Etapas do projeto:**

* 🔎 Consultas básicas
* 🎯 Filtros e ordenação
* 📊 Agregações
* 🔗 JOINs
* 🧩 Subconsultas
* 🧠 Desafios práticos

🔗 [Acessar projeto](https://github.com/Kofhe/SQL-para-An-lise-de-Dados)

---

### 🐍 Python & Pandas

Projetos de estudo voltados para **análise, exploração e tratamento de dados** utilizando Python e Pandas.

Também venho praticando técnicas de análise por meio de projetos próprios e bases de dados para estudo.
