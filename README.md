## 🖤 Sobre mim

🎓 **Ciência da Computação** — Pitágoras/Unopar Anhanguera  
💻 Experiência em **Sistemas, Sustentação e Tecnologia da Informação**  
📊 Projetos práticos em **Dados e Desenvolvimento Web**  
🏢 **Analista de Implantação Júnior — LWSA**

Minha trajetória em tecnologia inclui experiência com sistemas, documentação técnica, acompanhamento de demandas e apoio a projetos relacionados ao Prontuário do Paciente.

Durante minha experiência na Rede Mater Dei de Saúde, tive contato com o sistema **MV SOUL 3.0**, **SQL Oracle** e necessidades de usuários, desenvolvendo uma visão prática da relação entre tecnologia, processos e negócio.

Neste perfil, compartilho projetos e estudos envolvendo **SQL, Power BI, DAX, Power Query, Python, Pandas, HTML, CSS e JavaScript**.

## 📂 Projetos

### 🌙 [Lunara Store — Loja virtual](https://github.com/Kofhe/Lunara-Store)

Projeto de desenvolvimento web com identidade visual própria, explorando a criação de uma loja virtual e a construção de uma interface personalizada.

**Tecnologias:** HTML • CSS • JavaScript

### 📊 [Dashboard de Acompanhamento da Migração de Sistema](https://github.com/Kofhe/-Dashboard-de-Acompanhamento-da-Migra-o-de-Sistema)

Projeto de acompanhamento de informações e indicadores relacionados a testes, respostas de usuários e demandas de migração de sistema.

**Tecnologias:** Power BI • Excel • DAX

### 📈 [Dashboard de Demandas Fictícias](https://github.com/Kofhe/dashboard-demandas-ficticias-powerbi)

Dashboard desenvolvido com dados fictícios para praticar a análise de demandas, a visualização de informações e o acompanhamento de indicadores.

**Tecnologias:** Power BI • Análise de Dados

### 🐬 [SQL para Análise de Dados](https://github.com/Kofhe/SQL-para-An-lise-de-Dados)

Repositório de práticas e consultas SQL para desenvolver habilidades de filtragem, agrupamento, agregação e análise de dados.

**Tecnologias:** SQL • MySQL
